Study date: 2026-10-27. Evidence cutoff: separate analysis completed

## Result

With the registered 512-source comparison, bounded QMC exploration preserved
the fixed-PUCT first trajectory but did not clear the registered practical
uplift threshold. QMC succeeded in 1,096/2,048 source-root rows (53.515625%);
IID in 1,091/2,048 (53.271484375%); fixed PUCT in 272/512 (53.125%).

The sole primary, each source's four-root QMC success average minus its one
PUCT outcome, is **1/256 = +0.390625 percentage points**. The fixed approximate
model interval is **[-0.390625, +1.171875] percentage points**, below the
registered +2-point practical threshold at its upper end. The unchanged
precision-first rule returns **NO_PRACTICAL_UPLIFT_SIGNAL**. This is not a
claim of zero effect, equivalence, population coverage or general QMC failure.
Winner and scientific_decision remain null.

All 4,608 cells were regenerated byte-identically in the one approved separate
analysis. The subsequent stdlib-only, separately implemented saved-event check
matched every cell reduction, score/backup calculation, 2,048 QMC/IID pairs and
512 source anchors. It is not another experiment, a generative replay or an
independent reviewer. The later result-package qualification is summarized below.

Public evidence: [frozen plan](../preregistrations/countdown_search_value_puct_qmc_hybrid_20261027.plan.json), [source-level outcomes](../results/puct_qmc_series/outcomes.csv), [local verification summary](../results/README.md#verification--検証).

## Fixed policy and analysis units

Candidate `62941c23147de96f0e1d7c8d1921ed2036b44d6f`; plan digest
`c65146b28f3cec39ceae7f956cc536c59c0cee2f300b6e94f5d08fe07045423e`.
The prior is the existing greedy-rollout-error heuristic, **not an LM prior**.
All arms keep binary terminal backup (exact 1, otherwise 0), c=1 PUCT, visits,
arithmetic mean/m2, DAG sharing, proposal cache, canonical ties and stopping.

Writing U(a)=p(a)*sqrt(1+sum visits)/(1+edge visits), control scores Q+U.
QMC and IID use exactly control on trajectory 0, without planning, generating,
charging or advancing random material. Thereafter they score
Q+U*(0.5+original uniform). Q is not multiplied; m2 and normal values are not
selection terms. The fixed multiplier lies in 0.5..1.5, centered at 1, with no
outcome-based coefficient selection. Normals are still generated, stored and
coordinate-charged by the inherited material backend.

QMC uses `torch-sobol-full-sha256-cp-rotation-float51/v2`; IID uses
`sha256-counter-open-unit-float51/v2`. This is neither Owen scrambling,
Gumbel selection nor Bayesian uncertainty. Matched root labels do not create
common draws or whole-trajectory common random numbers. Adaptive selection
has no established fixed-integrand QMC convergence guarantee.

The cohort is the first 512 eligible unique solvable sources: six inputs 1..10,
target 100..999, generator 26102702, maximum 10,000 attempts. The plan excludes
1,499 historical/fixture task identities and 1,441 source identities, including
the preceding PUCT-return cohort. No favorable-outcome subset was selected.
The fixed roots are 524288..524291, with existing branch-0 derivation. There
are 2,048 QMC + 2,048 IID + 512 PUCT physical rows; root 0 on PUCT is a
deterministic identity, not a random replicate.

Each row has legal_action_scores cap 512 and six other guards of 100,000.
Total primary cap is 2,359,296. The analysis unit is **512 sources**, not 4,608
cells or 2,048 independent source-root pairs. Referencing each PUCT outcome
four times for a descriptive contrast does not create four PUCT observations.
QMC-minus-IID and IID-minus-PUCT are secondary and cannot replace the primary.

## Preserved anchor, later differences and success complementarity

All 512 sources have identical first-trajectory actions/child states/verifier
evidence across all nine physical rows. The first terminal was exact in 210
sources: 840 rows in each four-root arm and 210 PUCT rows. Later observations
add 256 QMC row successes, 251 IID row successes, and 62 PUCT source successes.
The initial anchor therefore holds; later PUCT success is not guaranteed.

For QMC versus the four descriptive references to PUCT, both succeeded in
1,074 pairs, QMC alone in 22, PUCT alone in 14, and neither in 938.
The 22 gains span 17 sources; the 14 losses span 10 sources. IID's corresponding
counts are 1,068 / 23 / 20 / 937, with gains/losses each spanning 15 sources.
All gain/loss coordinates, first-hit/censor work and metrics are retained in
diagnostics, not replaced by selected favorable examples.

Across four roots, QMC's union succeeds on 289 sources and IID's on 287,
versus 272 for one PUCT row. All-root success counts are 263 and 257.
These four-run unions use four primary budgets per source; they are not an
equal-budget success uplift or the primary estimand.

Of 2,048 QMC/IID pairs, 857 have identical full action sequences and 1,191
have a first divergence, always at the same state. All first trajectories
match. Divergence occurs no earlier than zero-based selection index 5;
461 first diverge at index 5. Every exact divergence and material decomposition
is retained. Same-history unperturbed-score choices differ from actual choices
in QMC 3,897/60,407 selections and IID 4,473/60,435. Before first exact they
differ in 3,869/36,686 and 4,445/36,727; binary Q is zero there. This passive
score check is **not a counterfactual unperturbed rollout**.

Repeated-state ordinary selections are QMC 40,858/60,407, IID 41,128/60,435,
and PUCT 10,419/15,113. Distinct terminal action sequences summed per cell are
6,313 / 6,224 / 1,408; repeated terminal observations are 5,272 / 5,377 / 1,493.
These are descriptive counts with unequal arm row counts, not independent
samples, novelty guarantees or evidence that one policy is globally optimal.
